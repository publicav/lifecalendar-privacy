Политика конфиденциальности — LifeCalendar

Обновлено: 3 августа 2026 г.

Приложение LifeCalendar («Жизнь») разработано как личный инструмент для визуализации жизни в виде сетки лет и недель.

Какие данные собирает приложение

Приложение не собирает, не передаёт и не хранит на серверах никакие персональные данные. Всё, что вы вводите — имя, фамилия, дата рождения, периоды жизни (садик, школа, университет, работа и т.д.) и выбранный язык интерфейса — сохраняется только локально на вашем устройстве, в защищённом хранилище приложения (Android DataStore).

Передача данных третьим лицам

Приложение не использует аналитику, рекламные SDK или сторонние сервисы сбора данных. Единственное взаимодействие с внешними сервисами — это переход по ссылке на страницу поддержки автора (донат), который открывается в браузере устройства и не связан с передачей ваших данных из приложения.

Удаление данных

Вы можете удалить все данные приложения в любой момент через настройки Android: Настройки → Приложения → LifeCalendar → Хранилище → Очистить данные, либо просто удалив приложение с устройства.

Разрешения

Приложение не запрашивает доступ к камере, контактам, местоположению, микрофону или другим чувствительным данным устройства.

Изменения политики

При изменении подхода к обработке данных эта страница будет обновлена, а дата обновления — изменена.

Контакты

По вопросам, связанным с этой политикой, можно связаться через страницу приложения в Google Play.
